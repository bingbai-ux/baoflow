# UI比較画面

すべてlocalhostの合成データを実際のNext.js画面で表示して撮影したものです。本番画面・実顧客データではありません。

変更前は公開基点 `6ab0c287dc941d394bbbcf56ecc43f617e08db63`、変更後は全ブラウザ回帰32件を通したUI差分。
`before`と`after`の同名ファイルを比較してください。

| 画面 | 幅 | 改善の見どころ |
|---|---|---|
| deal | 390px | 主操作までの縦幅・状況欄・工程選択 |
| storage-invoice | 390px | 履歴と作成入口を優先、概算は補助領域 |
| client | 390px | 出荷依頼という業務名、再読込で更新する範囲 |
| factory | 1280px | 未回答RFQを発注閲覧より上に表示 |
| logistics | 390px | 作業名・承認待ち区分・重複する0件操作の整理 |

完全な比較16枚ずつと全ルート76枚はローカル `tmp/ui-clarity` に保存。表示検査は32種のpageファイルとタブ・役割・認証画面を対象とした82表示。ブラウザfixtureは本番RLSを証明しません。
