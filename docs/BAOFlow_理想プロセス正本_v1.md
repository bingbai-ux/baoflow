## 0. 一言で言うと

**管理者（BAO）がクリックだけでほぼ入力でき、顧客・工場とのやり取りはメール＋ノーログインリンクで半自動、AIが返信下書きまで用意する、9工程1本線の受発注システム。**

## 1. 全体構造

- **1案件（プロジェクト）＝9工程の1本線**。常にプログレスバーで現在地と「希望納期まで残り◯日」を表示
- **入力はクリック選択が基本**、選択肢にない時だけ自由記入
- **外部（顧客・工場・配送業者）はログイン不要のトークンURL**で参加（裁定D5）
- **横断機能**: 右側チャット欄（開閉式・メールのやり取りをLINE風に表示・AI返信下書き自動生成）／全履歴保存→次回オーダーの下敷き

```
①プロジェクト作成 → ②商品登録 → ③工場見積依頼 → ④価格提示(見積書) → ⑤請求書・契約
→ ⑥入稿 → ⑦サンプル・本製造 → ⑧発送 → ⑨検収・完了
```

## 2. 工程別要件

### 工程① プロジェクト作成／取引先登録
- 「新規プロジェクト」クリック→**新規取引先／既存取引先**の2カード
- 既存: ソート・情報一覧から選択→担当者（複数いる場合は選択）→ブランド（裁定D1: 会社の下に任意登録。無ければスキップ）
- 新規: 顧客情報を入力して登録→そのまま選択状態へ
- 「次へ」でプロジェクト作成。希望納期を設定し、以後**残り日数を常時表示**

### 工程② 商品登録（本サービスの主要画面）
- ＋ボタンで商品追加。入力順: **商品詳細→見積数量（複数）→配送方法**
- 商品詳細は**全項目クリック選択**＋各項目に自由記入欄:
  - 種類・形状・ディテール＝**大分類/中分類/小分類**（設定の商品マスターで白が設計可能）
  - 素材／印刷色数／付属品（バルブ・ジップ等、**複数選択**）
  - サイズ: 縦×横×奥行、または直径×高さ（瓶等）、または「◯kg入る」指定。**未定なら空欄のまま登録可**
- 数量: 複数追加可。手入力＋**スロット（回転式）選択**
- 配送: 船便／エアー ×（工場手配／提携配送業者手配）。提携の場合は既存の料金見積ベースで自動概算
- サンプル要否・食品検査要否・備考
- 登録すると**商品名が一定形式で自動付与**され、内容一目瞭然のカード＋数量が下に並ぶ
- **コピーして差分だけ変更**（ジップ無し版など）／一覧は**ドラッグ&ドロップで並べ替え**／ゴミ箱アイコン→確認ポップアップで削除

### 工程②-M 商品マスターのカタログ自動取込（独立工程として実装）
- 設定>商品マスターで、工場を選んでカタログPDFをアップ→AIが読取:
  商品写真の切り出し・商品番号・サイズ・名前の日本語訳・大/中/小分類の自動判定→同一形式のカードに整頓
- 取り込んだ商品は**工場に紐づき**、商品登録時に選択肢として出る。複数工場に同じ商品がある場合は**両方の工場タグ**
- AIは裁定D7（Claude API最上位・画像読取）。読取結果は**草稿→白の確認で確定**（従来原則の維持）

### 工程③ 工場見積依頼
1. 商品登録完了→**顧客へ内容確認メール**（明細PDF添付＋確認リンク）。リンク先で内容表示→「この内容で進める」ボタン（裁定D2・ログイン不要）。明細の後日変更は再確認不要
2. 顧客確定→BAOにメール＋アプリ通知→「工場に見積を依頼する」ボタンが解放
3. 工場へ依頼メール（将来WeChatも検討）→工場はリンクから入力ページへ（裁定D5・トークン方式）:
   - 数量別単価（USD）／版代／色数による追加費／特殊加工（デボス・エンボス等を任意追加）
   - 送料: 船便・エアー、提携業者利用時は表示された工場住所→集荷先までの中国国内送料
   - 箱情報: 箱サイズ・入数・重量（送料計算用）
   - **日数**: 版代製作／サンプル製作／本製造／国内配送／船便／エアー（「15〜20日」のような幅＝バッファ入力可）
   - 備考・写真・添付ファイル／**一時保存可**→「確定」でBAOに通知

### 工程④ 取引先価格提示（お見積書）
- 工場回答が表に反映: 送料込みトータル・1個あたり原価
- **提示価格の直接入力 ⇄ 原価率入力の双方向自動計算**（%は1%刻みのスクロール）
- 円換算で表示: 1個あたり原価／総額／税込額／**想定利益**
- 「第一次お見積書として確定」→顧客へメール（本文＋PDF＋閲覧リンク）。製造日数も見積書に記載
- 顧客は**承認／差し戻し**（条件・数量変更の要望付き）。差し戻し→工場へ第2回依頼→再提示…**何回でも。全版の履歴を保存・展開表示**
- 承認→「請求書を発行する」ボタン解放

### 工程⑤ 請求書発行・契約
- 情報一覧確認→発行日・振込期限を選択→発行→顧客へメール＋請求書
- 顧客はリンクから内容確認→**承認ボタン（＋日時・操作記録の保存）で契約成立**（裁定D4）。双方に成立メール
- 成立→「入稿に進む」解放

### 工程⑥ 入稿
- 2パターン対応: **(a)顧客がデータを直接用意**／**(b)工場が雛形を用意→顧客デザイナーが流し込み**
- アップロード→相手側へ自動通知→リンクからダウンロード、の双方向中継。BAOは閲覧＋差し止め可、案件ごとに「BAO確認を挟む」スイッチ（裁定D3）
- **工場への前払い**（50% or 30%、事前設定）: 振込確認を記録してから「製作開始」へ進める。**入金済みかどうかを必ず可視化**

### 工程⑦ サンプル製造・本製造
- サンプルありの案件は本製造の前にサンプル工程（商品登録時のサンプル要否で分岐）。サンプル製造日も管理
- 工場は完成時に**動画・写真をアップ**→通知→顧客は**コメント欄で修正指示**（修正データ添付可）→微調整→本製造へ
- 本製造中は**納期からの逆算で「あと◯日」「到着目安」を常時表示**

### 工程⑧ 発送
- 製造完了→工場が動画・写真・備考つきで完了報告→BAO確認→配送手配
- **段ボール貼付ラベルを自動生成（PDF）**、工場がダウンロード可能
- BAOの「発送依頼」→工場は梱包、**梱包写真＋ラベル貼付写真を必須提出**→追跡番号＋追跡URLを入力して「発送完了」
- BAO・顧客に発送通知→以後追跡番号で現在地を確認（将来: ステータス同期通知）
- 食品検査がある案件は検査日数をスケジュールに織り込む
- 提携配送業者利用時: 業者用トークンアクセスで荷物情報を共有し、受け渡しをシステム上で完結

### 工程⑨ 検収・完了
- 到着→顧客に通知→顧客が確認し「受領」ボタン→**納品書を自動送付**→案件完了
- 全データは履歴として保存され、**次回オーダー（リピート）の下敷き**になる

## 3. 横断機能

| 機能 | 要件 |
|---|---|
| チャット欄 | 案件画面の**右側に開閉式トーク欄**。実体はメールのやり取りをLINE風スレッド表示。写真・ファイル投稿可 |
| AI返信下書き | 顧客・工場からメッセージが届いた時点で**AIが返信文を自動生成し下書き保存**。BAO担当者は確認・修正して送るだけ |
| プログレスバー | 全画面で9工程の現在地＋残り日数を表示 |
| 履歴 | 見積の全版・やり取り・承認記録・写真を案件に永続保存 |

## 4. 裁定一覧（白が否認しない限り確定）

| # | 裁定 |
|---|---|
| D1 | ブランドは取引先の下の任意マスター。作成フローは会社→（ブランド）→担当者 |
| D2 | 顧客の承認は「リンク→内容ページ→承認ボタン」。ログイン不要・ワンクリック直承認は禁止（メールスキャナ誤承認の実害防止） |
| D3 | 入稿の中継は既定素通し＋BAO全件閲覧＋差し止め可＋案件別「確認を挟む」スイッチ |
| D4 | 契約成立＝承認ボタン＋日時＋操作記録。外部電子署名サービスは必要になったら追加 |
| D5 | 外部参加はトークンURL方式に一本化。ログイン式ポータル3種は封印（削除しない） |
| D6 | ステータスは新9工程に一本化。既存11案件は対応表で移行し白が目視確認。旧系統は凍結 |
| D7 | カタログ読取・AI返信は接続済みClaude APIの最上位モデル（「astra」の正体は白に確認中） |
| D8 | デザインは現行の**F&C Design System**（CLAUDE.md）を維持。今回は見た目の刷新ではなく動線の刷新 |
