# 外部依存・未合格必須項目

| 必須項目 | 必要な正本入力 | 必要な権限/契約 | 今の動作 |
|---|---|---|---|
| 発行時の最新FX自動取得 | 使用データ元/endpoint、USD→JPYとCNY→JPYの方向、鮮度許容/休日/取得失敗時の停止・明示手入力方針、丸め | 選ぶ提供元の利用許諾と読取API権限。既存契約がある場合そのmetadataを確認し、鍵入力は本人境界。新有料契約/新credentialは作らない | 確認済み手入力rate/source/as_ofを版に固定。自動取得なし |
| RMB原価/費目 | 工場の提示通貨、RMB/USD/JPYの単価と総額区別、費目別通貨、変換rate/source、請求通貨/税/丸め | 原価通貨の意味を変更するschema/RPC審査が必要。金融API/新契約自動追加なし | 既存USD工場単価＋USD/JPY費目＋JPY売価。RMB入力なし |
| 海源正式送料・宛先 | 正式料金表の版/有効期間、air/sea×食品区分、最低重量/容積換算/端数/追加料金/税、各分岐の正式住所/宛名/郵便番号/連絡先/登録配送業者 | 正式資料利用と既存宛先登録/共有の確認。業務送信先・送信許可は別。推測値/住所は採用しない | 手動確認した宛先source/食品検査状態。正式料金/宛先マスタ連携なし |
| 実追跡/食品検査連携 | 対象carrierとtracking番号、正本API/イベント仕様、FAINS等の手続範囲と担当 | 既存サービスのtracking読取scope/利用契約。新契約/課金は承認対象。申請書込/実物流メールは別 | 手動イベントを未接続と表示。carrier配達≠顧客受領 |
| 相手先との双方向チャット | 相手単位（案件/会社/ユーザー）・公開履歴・添付・通知・保持方針 | 顧客/工場/物流への会話読取/投稿RLSとRealtime/通知の審査。既存権限を勝手に広げない | 右側折畳みの連絡記録。相手への送信/チャット受信ではない |
| 本番公開受入 | fresh backup成功時刻/復元可能範囲、実復元手順、以降本番書込差分、既存6件の原仕様根拠 | バックアップ画面再認証・未公開sample/Stage4–11権限/migrationの承認。export/新課金なし | Stage1だけ公開済み。旧見積6件を推測で紐付けない |
| 本番メール | 正しいproject/Production scopeで利用可能な既存key metadata、検証済み送信元/ドメイン、非秘密APP_URL、配信先の許可 | 秘密値の取得/複写/再送なし。必要な新入力は本人handoff。外部テストメールは未承認 | Mailpitで受信/PDF添付/金額期限確認。本番到達を合格扱いしない |

発注済みの価格変更/金銭相殺・返品回収・新倉庫拡張はStage11の再交渉機能対象外。正確な根拠のない既存6件のvariant補完も行わない。
